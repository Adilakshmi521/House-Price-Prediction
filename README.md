# House Price Prediction

## Alfido Tech – Machine Learning Internship (Task 2)

### Project Overview
This project predicts house prices using Machine Learning algorithms. It analyzes housing data, performs data preprocessing, trains multiple regression models, and compares their performance.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab

### Machine Learning Algorithms
1. Linear Regression
2. Random Forest Regressor
3. Gradient Boosting Regressor

### Project Workflow
1. Data Collection
2. Exploratory Data Analysis
3. Data Preprocessing
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Model Saving
8. House Price Prediction

### Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

### Project Files
- House_Price_Prediction.ipynb
- best_house_price_model.pkl
- scaler.pkl
- imputer.pkl
- model_comparison.csv
- README.md
- requirements.txt

### How to Run
1. Install the required libraries.
2. Open the Jupyter Notebook.
3. Run all cells sequentially.
4. View the model comparison and predictions.

### Conclusion
This project demonstrates how machine learning regression algorithms can be used to predict house prices and compare model performance.

*Developed as part of the Alfido Tech Machine Learning Internship.*
